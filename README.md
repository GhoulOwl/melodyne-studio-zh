# Melodyne Studio 5.4.2 简体中文补丁

为 Melodyne 5.4.2.006 提供 macOS 与 Windows x64 简体中文界面。项目只包含翻译数据和补丁脚本，不包含 Melodyne 程序、音频核心、授权信息或安装包。

| 平台 | 脚本 | 安装方式 |
| --- | --- | --- |
| macOS | `install.py` | 生成独立的中文版应用副本，见下文 |
| Windows x64 | `install-windows.cjs` | 备份后替换共享核心中的语言字典，见 [Windows 安装与恢复说明](WINDOWS.md) |

两种脚本分别核验各自平台的版本和语言资源。Windows 支持 2,040 条翻译，已验证独立程序启动与中文菜单；音频功能与宿主插件尚未完成实测。需要 Node.js 22 或更高版本，详情见 [WINDOWS.md](WINDOWS.md)。

## macOS 安装

为 Melodyne 5.4.2.006 的 macOS **独立应用**生成一个简体中文副本。项目包含翻译数据与补丁工具，不包含 Melodyne 程序、音频核心、授权信息或安装包。需要先自行安装并取得 Melodyne 的使用许可。

> 非官方项目，与 Celemony 无关联。翻译包含机器翻译及人工修订，少用界面仍可能存在错译或排版问题。欢迎通过 Issue 反馈具体位置和截图。

## 兼容范围

- macOS，已安装 Melodyne 5.4.2.006（当前仅在一台 Apple Silicon Mac 的 Studio 独立版上测试）。
- **必须与本项目已测试的原版文件指纹一致**。同为 5.4.2.006，若安装包、版本或文件不同，也可能被拒绝；这是正常的保护措施，不要绕过指纹检查。
- 只处理独立应用；AU、VST3、AAX 插件及其他版本尚未适配或验证。
- 基于英文界面词条构建；如界面没有显示中文，请在偏好设置中选择 English，然后重启中文版。

## 使用

1. 安装 Melodyne 5.4.2.006，关闭 Melodyne 和音频宿主，并保留原始安装文件。
2. 下载本仓库：GitHub 页面点击 **Code → Download ZIP**，解压。
3. 打开 macOS「终端」，输入 `python3 `（末尾有空格），将解压目录中的 `install.py` 拖入终端，再按回车。
4. 出现 `完成` 后，在访达打开「个人文件夹 → 应用程序」，启动 **Melodyne 中文.app**。

需要 macOS 的 Python 3 和 `codesign`。脚本从电脑现有安装读取文件，先检查版本专用文件指纹，再在个人应用程序目录生成独立副本。它不会覆盖原来的 Melodyne 应用或系统插件；若目标已存在，会停止并提示。

脚本会在 `/Users/Shared/MelodyneZH-<当前用户数字 ID>/` 建立仅当前用户可访问的运行资源目录。**中文版需要此目录才能启动，不要单独删除或移动。** 修改后的本地副本会使用本机临时签名（ad-hoc signing），不是 Celemony 官方签名；系统或授权行为可能因机器和环境不同而变化。

## 移除

先退出中文版。将 `~/Applications/Melodyne 中文.app` 移到废纸篓；再将上面显示的对应 `MelodyneZH-<用户 ID>` 资源文件夹移到废纸篓。保留自己的原版安装。若在其他位置安装了中文版或自定义了资源目录，请删除对应位置的文件。

## 用自己的原始应用路径

如原始应用不在默认位置，可在终端使用：

```sh
python3 install.py --source-app '/path/to/original/Melodyne.app'
```

支持 `--output` 和 `--support-dir` 指定输出；资源目录的绝对路径含末尾斜线不能超过 46 字节。运行 `python3 install.py --help` 查看参数。请勿把资源目录放在会被系统清理的临时目录中。

## 验证与局限

开发测试中，独立版能打开合成音频、移调音符、撤销并导出 WAV；自动检查确认原始字典和翻译后的占位符及记录数量一致。可分发脚本在同一台机器上以原始应用备份重建，得到与测试版相同的翻译字典，并验证了隔离资源加载。尚未覆盖所有窗口、宿主、架构与系统环境；请先用副本和非重要工程测试。软件更新会改变文件指纹，通常需要重新适配。
